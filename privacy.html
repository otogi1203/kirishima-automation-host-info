アプリについてプライバシーポリシー

プライバシーポリシー

この説明は、現在のKirishima Automation HostのGoogle Calendar読取処理を対象とします。

1. Calendar情報へのアクセスと利用

接続したアカウントのprimary Calendarから、予定の状態、タイトル、開始・終了、時間の占有情報、繰り返し予定を識別するための元の開始情報を取得します。予定の説明、場所、参加者、主催者、会議情報、予定ID、カレンダーIDは要求しません。

calendar.events.readonly の許可範囲はアクセス可能なすべてのカレンダーの予定の表示ですが、Hostの読取先はprimary Calendarに固定されています。基準時刻から24時間の予定を最大20件、AutomationのCoreへ渡す目的で利用します。取得時には前後48時間の余裕を設け、対象外の予定をメモリ上で除外します。予定の内容はRun処理中のメモリで扱い、Calendarのローカル同期データベースは作りません。

2. Google Sign-Inのidentity情報

Google Sign-In SDKは、基本identity scopeであるemailとprofileを要求し、ID tokenの情報、または必要に応じてGoogleのuserinfo応答からメールアドレス・氏名・プロフィール画像等を扱います。Googleの応答にはopenidやuserinfo.*という表記のscopeが含まれる場合があります。SDKがidentity情報を扱うことと、霧島のAutomationがその情報を利用することは別です。

霧島側はGoogleの不透明なアカウントIDから作ったダイジェストをMac内のアカウント結び付けに使います。メールアドレスとプロフィールは、この結び付け、Automation Context、Receipt、診断ログ、画面表示には使いません。SDKの認証状態にはID tokenなどidentity情報を含むデータが入り得るため、identity情報を一切取得・保存しないとは説明しません。

3. 保存と共有

Googleへの接続情報はSDKが管理し、Host専用のMacのdata-protection Keychainに保持します。アカウント結び付けもMac内に保持し、Googleの生のアカウントIDやメールアドレスを共有Automation Storeへ保存しません。

Calendar情報の取得に関するReceiptはMac内に保存します。実行を関連付ける識別子、取得対象がprimaryであること、取得対象時間枠、タイムゾーン、件数、切り詰めの有無、処理結果、通信先の種類、記録時刻などの構造化metadataを含みます。予定タイトルや個々の予定の時刻、予定ID、アカウントidentity、認証情報はReceiptに記録しません。

共有Automation Store（Supabase）にはAutomationの定義、実行状態、RunやHostの識別情報などの構造化metadataを保存します。このCalendar処理では予定内容、Google認証情報、アカウントの結び付け、ローカルReceipt本文を共有Storeへ送りません。

4. 通信と外部への送信

Googleへの認証・認証状態の更新とCalendar APIの読取に必要な通信を行います。Calendarへの問合せにはprimary指定、取得対象時間枠、返却fieldの制限、ページ取得に必要な情報を使います。共有Automation Storeとも実行管理のために通信します。現在のCalendar処理には外部AI・Agentへの送信、外部への通知・配信、広告目的の利用はありません。Calendarデータをこの説明サイトへ送る機能もありません。

本アプリによるGoogle APIから取得した情報の利用および他のサービスへの転送は、Limited Useの要件を含むGoogle API Services User Data PolicyとGoogle Workspaceのユーザーデータ・デベロッパーポリシーに従います。

5. 接続解除と権限取消

Hostの接続解除は、SDKのローカルsign-outと、Mac内のアカウント結び付けの削除を行います。Googleアカウント側のアプリのアクセス権を取り消す処理ではありません。Google側の権限取消は、本人がGoogleアカウントの接続管理で別途行う必要があります。操作時には、Calendarの読取に使用しているアカウントを確認してください。

Hostの接続解除によって既存のReceiptや共有Storeの実行記録を削除する仕組みはありません。現在、Receiptの保持期間・専用削除操作は定められていません。自動削除や特定日数での消去、完全消去は約束しません。

6. 説明サイトの閲覧

このサイトには外部スクリプト、アクセス解析、フォーム、ログイン機能を設けません。GitHub Pagesで公開する場合、GitHubはサイト訪問者のIPアドレスをセキュリティ目的で記録・保存すると説明しています。これは説明サイトへのアクセスに関するホスティング側の記録であり、Hostが読むCalendarデータをGitHubへ送信することとは別です。

GitHub Pagesの取扱いはGitHub Pagesの説明およびGitHubのプライバシー声明をご覧ください。Googleとの通信はGoogleのサービスにも関わります。
