Mac Automation Host の説明

アプリについてプライバシーポリシー

Kirishima Automation Host

Kirishima Automation Host は、本人が利用するMacで、設定されたスケジュールに従ってGoogle Calendarの予定情報を読み取り、ローカルのAutomation処理へ渡すためのアプリです。このページはアプリの説明とデータ取扱いを示すものです。現在、アプリの一般配布は行っていません。

現在の機能

接続したGoogleアカウントのprimary Calendarを読み取ります。処理の基準時刻から24時間の範囲で、予定のタイトル、開始・終了、終日予定の区別、予定による時間の占有、繰り返し予定の区別を扱います。Automationへ渡す予定は最大20件です。

Googleへの取得範囲には、終日予定とタイムゾーンの差に対応するため、前後48時間の余裕を設けています。24時間の対象範囲から外れる予定はメモリ上で除外します。取得件数自体を20件に限定する仕組みではありません。

Googleへの接続と権限

Google Calendarの権限として明示要求するのは calendar.events.readonly です。この権限はGoogle上では、アクセス可能なすべてのカレンダーの予定を表示できる範囲ですが、現在のHost実装が読み取る対象はprimary Calendarだけです。予定の作成・変更・削除は行いません。

接続にはGoogle Sign-In SDKを使用します。SDKは基本のidentity情報を取り扱いますが、霧島のAutomationはメールアドレスやプロフィールをContext、Receipt、診断ログ、アカウントの結び付け、画面表示に使いません。詳しくはプライバシーポリシーをご覧ください。

実行結果の意味

現在の完了結果は、Calendar情報を取得・検証し、AutomationのCoreへ渡し、ローカルにアクセス記録を残したことを意味します。AIによる処理、提案生成、通知、外部への配信は現在のHostのCalendar処理には含まれていません。
